# Game-of-Cece

Minispiele für Cece. Reines HTML, CSS und JavaScript, einfach `index.html` öffnen
oder über GitHub Pages aufrufen.

* [Blöcke](blocks.html) – Blöcke stapeln, volle Reihen bringen Blumenmünzen
* [Avatar](avatar.html) – Figur zusammenstellen, Teile mit Münzen kaufen
* [Rekorde](marcas.html) – Bestmarken aller Spiele

## Gemeinsam mit Games for Cece

Läuft parallel zu [Games-for-Cece](https://github.com/blablubbbb/Games-for-Cece).
Beide Seiten liegen unter `blablubbbb.github.io` und teilen sich deshalb den
`localStorage`: `cece-coins` (Münzen), `cece-avatar` (Avatar und gekaufte Teile)
und `cece-marcas` (Rekorde). `avatar.js` und `marcas.js` sind von dort kopiert;
in `marcas.js` steht hier nur die eigene Spieleliste. Kommen dort neue
Avatar-Teile dazu, `avatar.js` einfach wieder herüberkopieren.

Der Titel „Game of Cece" auf der Startseite ist ein versteckter Link nach
Games for Cece.
